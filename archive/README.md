# Research Project Archive

This archive preserves all historical artifacts, initial development logs, intermediate audit packages, and legacy models generated throughout the research lifecycle.

## Contents

1. **`baseline_artifacts/`**: Initial raw baseline models, preliminary data splits, and early exploratory reports.
2. **`audited_final_results/`**: The intermediate audit package and development scripts preceding the Phase 1 train/validation leakage remediation.
3. **`research_repair_output/`**: The preliminary defect repair workspace for DEF-01 through DEF-07.
4. **`audit/`**: Historical intermediate confusion matrix exports.
5. **`root_reports/`**: Intermediate verification logs (`POST_REPAIR_*.csv`, `DEFECT_REPAIR_*.md`, etc.) superseded by the canonical reports in `reports/` and metrics in `results/metrics/`.
6. **`scratch/`**: Temporary scratch debugging scripts and interactive cell extractions.

## Provenance and Preservation Note
Nothing in this archive has been permanently deleted or altered. All historical files are mirrored in the dated external backup (`backup_crop_recommendation_20261020`) and indexed in [`CLEANUP_MANIFEST.csv`](file:///CLEANUP_MANIFEST.csv).
